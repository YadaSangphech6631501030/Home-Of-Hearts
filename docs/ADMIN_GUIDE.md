# Admin Guide

คู่มือการใช้งานฝั่งผู้ดูแลระบบ Home of Hearts Residence

## Login

เข้าใช้งานที่

```text
http://localhost:3000/
```

บัญชี admin เริ่มต้นสร้างได้ด้วยคำสั่ง

```bash
npm run seed
```

หลัง seed แล้วควรเปลี่ยนรหัสผ่านก่อนใช้งานจริง

## Dashboard

หน้า `/admin/index.html` ใช้ดูภาพรวมของระบบ เช่น

- จำนวนห้องทั้งหมด ว่าง/ไม่ว่าง
- สถานะรายการแจ้งซ่อม
- สรุประบบเงินหอพัก
- สรุปพัสดุ
- รายการแจ้งเตือน/ประกาศล่าสุด

## ระบบหอพัก

หน้า `/admin/dormitory.html`

- ดูห้องพักแยกตามชั้น
- กรองห้องตามชั้นหรือสถานะ
- ค้นหาเลขห้อง
- เปิดหน้ารายละเอียดห้อง

หน้า `/admin/room-detail.html?roomNumber=101`

- ดูข้อมูลผู้เช่าปัจจุบัน
- เพิ่มผู้เช่า
- แก้ไขข้อมูล
- ย้ายออก
- ดูประวัติผู้เช่าและข้อมูลที่เกี่ยวข้องกับห้อง

## ระบบแจ้งซ่อม

หน้า `/admin/maintenance.html`

- ดูรายการแจ้งซ่อมจากผู้เช่า
- กรองตามสถานะ ประเภท วันที่ และคำค้นหา
- เปิดดูรายละเอียด
- แก้ไขสถานะ วันนัดหมาย และวันเสร็จสิ้น
- ลบรายการ

## ระบบเงินหอพัก

หน้า `/admin/billing.html`

- สร้างรอบบิล
- สร้างบิลรายห้องจากรอบบิล
- กำหนดค่าเช่า ค่าน้ำ ค่าไฟ และหน่วยที่ใช้
- แก้ไข/ลบข้อมูลบิล
- ผู้เช่าจะเห็นบิลล่าสุดในหน้า user billing

## ระบบพัสดุ

หน้า `/admin/parcels.html`

- เพิ่มพัสดุใหม่ให้ห้องที่มีผู้เช่า
- อัปโหลดหรือระบุรูปพัสดุ
- แก้ไขสถานะเป็นรอรับ/เสร็จสิ้น
- ดูรูปพัสดุ
- ลบรายการ

## ระบบประกาศ

หน้า `/admin/announcements.html`

- เพิ่มประกาศ
- ลบประกาศ
- ประกาศจะแสดงให้ผู้เช่าเห็นในหน้า user และ notification

## ระบบติดต่อ

หน้า `/admin/contact.html`

- แก้ไขเบอร์โทร อีเมล Facebook Line ที่อยู่
- แก้ไข QR Code/ข้อมูล Line ของหอพัก
- ข้อมูลนี้จะถูกดึงไปแสดงในหน้า contact ฝั่ง user
