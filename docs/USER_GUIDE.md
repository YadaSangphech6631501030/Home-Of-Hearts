# User Guide

คู่มือการใช้งานฝั่งผู้เช่า Home of Hearts Residence

## Login

เข้าใช้งานที่

```text
http://localhost:3000/
```

ผู้เช่าสามารถ login ด้วยเลขห้องหรืออีเมลตามบัญชีที่ admin สร้างไว้

## Dashboard

หน้า `/user/index.html`

- ดูข้อมูลแจ้งเตือนของห้อง
- ดูพัสดุใหม่
- ดูสถานะรายการแจ้งซ่อม
- ดูประกาศจากหอพัก
- เปิด notification popup จากไอคอนกระดิ่ง

## ติดต่อหอพัก

หน้า `/user/contact.html`

- ดูเบอร์โทร อีเมล Facebook Line และที่อยู่
- ดู QR Code/Line จากข้อมูลที่ admin ตั้งไว้

## แจ้งซ่อม

หน้า `/user/maintenance.html`

- เลือกประเภทช่าง
- กรอกหัวข้อและรายละเอียด
- ส่งคำขอแจ้งซ่อมไปยัง admin
- admin สามารถอัปเดตสถานะ วันนัดหมาย และวันเสร็จสิ้นได้

## ชำระค่าหอพัก

หน้า `/user/billing.html`

- ดูบิลล่าสุดของห้อง
- ดูรายการค่าเช่า ค่าน้ำ ค่าไฟ และยอดรวม
- กดปุ่มชำระเงินเพื่อเปิด popup QR Code
- ดูประวัติการชำระได้จากปุ่มประวัติ

หน้า `/user/billing-history.html`

- ดูรายการบิลย้อนหลัง
- ดูสถานะ วันที่ชำระ และยอดเงิน

## พัสดุ

หน้า `/user/parcels.html`

- ดูพัสดุของห้องตัวเอง
- กรองข้อมูลตามประเภท ขนส่ง สถานะ วันที่ และคำค้นหา
- เปิดดูรูปพัสดุจากรายการที่ admin เพิ่มไว้

## ประกาศ

หน้า `/user/announcements.html`

- ดูประกาศจากหอพัก
- กดรายการเพื่ออ่านรายละเอียดแบบ popup
- ประกาศจะยังอยู่จนกว่า admin จะลบออก
